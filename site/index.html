Crush millions of data points into smooth visualizations.

High-performance data primitives for browser visualization. Written in Rust, compiled to WebAssembly, with a pure-JS fallback. The missing compute layer between raw data and chart libraries.

Zero data loss — your original data stays intact. vizcrush picks the points that matter for your screen.

AI-native. MCP built in.

vizcrush ships with an MCP server. AI coding agents (Claude Code, Cursor, Copilot) can invoke compute tools directly — no docs needed.

  • 23 tools: downsample, bin, spatial, stats, sort, normalize, AI
  • 3 prompts: optimize_chart, profile_data, migration_guide
  • stdio + HTTP transport, CSV file input
